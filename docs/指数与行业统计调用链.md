# 指数与行业统计调用链

- 更新日期：2026-08-12
- 范围：当前正式新管线 `FormulaBatch + BatchFactorEngine`
- 目的：记录行业分类统计、指数成分统计和单指数特征广播的实际用法与调用链

## 1. 方法总览

| 场景 | 入口 | 输出 shape | 说明 |
|---|---|---|---|
| 行业/分类统计 | `group_mean/sum/std/demean/zscore(values, group)` | `T × N × S` | 按 group code 统计后回填到每只资产 |
| 指数成分 reduce | `index_member_stat(values, member, method=...)` 或 `member_mean/sum/std` | `T × 1 × S` | 返回成分池单值时间序列 |
| 指数成分 transform | `member_demean/zscore` | `T × N × S` | 只在成分位置输出，非成分为 `NaN` |
| 单指数特征 | `select_index_feature(values, code)` | `T × 1 × S` | 选择后由 NumPy 在普通运算或输出边界广播 |

`T/N/S` 分别表示日期、资产和 step 轴。

## 2. 行业分类统计

新管线目前没有 `industry_mean()` 一类行业专用 helper，使用时显式加载行业 code，再调用通用 `group_*` 算子：

```python
batch = FormulaBatch.from_text(
    common_inputs="""
        value = source("stk.1d.DailyReturn")
        industry = source("stk.1d.industry_code.SW2021.L1")
    """,
    formulas={"alpha": "factor = group_mean(value, industry)"},
)
```

当前显式业务数据源为 `stk.1d.industry_code.SW2021.L1`，对应 `SmartQuant.ReturnDaily.IndustryCodeNew`。Catalog 扫表时也会把 `IndustryCode`、`SecondIndustryCode`、`IndustryCodeNew` 和 `SecondIndustryCodeNew` 识别为 `CODE` 类型。

调用链：

```text
source(行业 code)
  -> SourceRefExpr
  -> DataProvider.describe_many(): ValueKind.CODE
  -> Compiler 降低为 SourceTerm
  -> group_* OperatorTerm
  -> same_asset_domain 校验 values/group 使用同一资产轴
  -> Runtime.bind_many() / load_many()
  -> _group_stat_kernel 按组统计并回填
  -> T × N × S
```

这是 operator 内的分组 gather/scatter，不是 singleton 广播。分类缺失或为负数时对应输出为 `NaN`。

## 3. 指数成分统计

推荐在公式中显式声明成分 mask：

```python
batch = FormulaBatch.from_text(
    common_inputs="""
        value = source("stk.1d.DailyReturn")
        member = source("stk.1d.is_member.CSI300")
    """,
    formulas={
        "alpha": "factor = index_member_stat(value, member, method='mean')"
    },
)
```

`index_member_stat()` 不会自动查找指数成分，只把 helper 展开为已有 operator：

```text
mean -> member_mean
sum  -> member_sum
std  -> member_std
```

调用链：

```text
index_member_stat(values, member, method)
  -> HelperExpr
  -> Compiler._expand_helpers()
  -> member_mean/member_sum/member_std OperatorExpr
  -> asset_reduce_domain：匿名 singleton 资产轴
  -> _member_reduce_kernel
  -> T × 1 × S
  -> 后续普通运算或输出边界广播
```

直接使用 `member_demean/zscore` 时不做 reduce，结果保留完整资产轴。成分 mask 只有严格等于 `1.0` 才入池，缺失值按非成分处理。

当前正式配置显式提供 `stk.1d.is_member.CSI300` 和 `stk.1d.index_weight.CSI300`。`member_*` 可使用动态 `sample_mask` 和 `weight`：

```python
factor = member_mean(value, member, sample_mask=tradable, weight=index_weight)
```

这两个具名数组参数作为 Term 依赖进入 DAG，与 `method`、`window` 等编译期字面量参数分开。

## 4. 单指数特征选择与广播

```python
batch = FormulaBatch.from_text(
    common_inputs="""
        stock_close = source("stk.1d.ClosePrice")
        index_close = source("idx.1d.ClosePrice")
    """,
    formulas={
        "alpha": "factor = stock_close / select_index_feature(index_close, 3145)"
    },
)
```

`code` 必须是本次 `idx` 资产轴上的真实代码。

```text
select_index_feature(index_values, code)
  -> HelperExpr
  -> __select_asset(expected_asset_type="idx")
  -> 编译期将 code 解析为 position
  -> select_by_pos(axis=1, keepdims=True)
  -> T × 1 × S slice/view
```

新管线不产生 `broadcast_cs`、`broadcast_ts` 或指数专用广播 Term。物理广播只在两个位置发生：

1. `T × 1 × S` 与 `T × N × S` 参与普通 NumPy 运算时；
2. singleton 是最终公式输出时，Runtime 在输出边界调用 `np.broadcast_to()`。

日频 `T × 1 × 1` 指数特征用于分钟频任务时，可同时广播资产轴 `1 -> N` 和 step 轴 `1 -> target_step_count`。

## 5. Legacy 边界

`factor_engine.legacy` 仍保留 `industry_stat()`、`index_member_stat(..., broadcast=True)` 和 `broadcast_index_feature()` 等历史 helper。它们使用 `Planner -> broadcast_cs/broadcast_ts -> Executor` 的显式广播路径，但这些广播算子未进入当前默认 Registry。

因此 legacy 仅用于追溯旧实验；新任务统一使用本文前四节的新管线语义。
