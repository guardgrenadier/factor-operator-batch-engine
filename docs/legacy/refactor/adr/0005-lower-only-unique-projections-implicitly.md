# ADR 0005：只自动展开唯一投影，聚合与 PIT 政策必须显式

- 状态：已接受
- 日期：2026-07-24

## 背景

因子公式可能引用与任务域不同的资产轴或频率。完全禁止自动转换会使研究表达式过于复杂；在 Runtime 中隐式转换又会隐藏依赖、妨碍合法性检查，并让执行结果依赖未记录的政策。

跨域转换可以按坐标基数区分：

- 每个目标坐标最多能唯一确定一个源坐标；
- 一个目标坐标对应多个源坐标，需要聚合或选择。

## 决策

采用统一原则：

> 如果每个目标坐标最多能由一个源坐标唯一确定，可以在编译期自动投影；如果一个目标坐标对应多个源坐标，必须由公式显式声明如何聚合或选择。

自动投影只发生在领域规范化阶段，并被展开为 Canonical IR 中的显式节点。Runtime 不进行任何隐式资产或频率转换。

`ExecutionDomain` 决定目标资产和目标频率，叶子数据规格决定源资产和源频率。转换方向不通过算子是否存在来猜测。

## 资产轴规则

- `stk → cb`：当每个目标转债通过受信任的标准映射唯一找到一个正股时，可以自动展开投影。
- `cb → stk`：一只股票可能对应多只转债，必须显式提供 selector 或 reducer。
- 存在多个映射关系或无法唯一选择映射时，必须显式指定；否则编译失败。

映射数据的完整性和 PIT 由对应数据产品契约负责。引擎只校验其结构是否满足投影算子要求。

## 频率轴规则

- 同频率直接对齐。
- `1d → intraday`：可以自动展开到目标 step 轴的结构广播，但不自动添加 delay。
- 粗粒度日内频率到细粒度日内频率：只有在时间戳、available-time 和默认投影规则能唯一确定源坐标时，才能自动展开 as-of 投影。
- 细粒度到粗粒度、日内到日频：一个目标坐标对应多个源观测，必须显式声明聚合方式。
- 找不到唯一、已注册的频率投影规则时，编译失败。

引擎不负责判断某个公式是否需要 delay 来避免未来信息。研究者、已确认公式的生产方或自动挖掘算法负责显式表达 PIT 政策。

## 编译边界

编译链路为：

```text
Surface AST
  -> 研究适配与领域规范化
  -> Canonical IR
  -> 通用编译、依赖提取与计划生成
  -> 数据绑定
  -> Runtime
```

在生成输入需求后，不再允许发生 delay 注入、mask 注入、资产映射或频率转换。

## 影响

- 当前 `Planner` 自动注入 `delay_lf` 的行为不进入新核心编译器。
- 研究层可以继续提供 `FeatureDef.delay_lf` 等便利能力，但必须在进入 Canonical IR 前展开为显式节点。
- 自动投影新增的 mapping feature 和其他数据依赖会出现在 `InputRequirements` 中。
- 编译结果应能解释从原始公式到 Canonical IR 的所有自动展开。
- 映射规则和频率投影规则需要版本化，并参与计划语义或 lineage。
