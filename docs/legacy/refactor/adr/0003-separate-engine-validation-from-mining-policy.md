# ADR 0003：分离引擎可执行性校验与挖掘策略

- 状态：已接受
- 日期：2026-07-23

## 背景

所有入口都需要在执行前发现通用错误，但自动因子挖掘还会对候选公式施加搜索空间、复杂度、业务意义和研究质量方面的约束。如果两者混在引擎中，计算内核会依赖具体挖掘算法。

## 决策

引擎只负责通用可执行性校验：公式是否符合其公开语言、算子契约、输入规格和批次计算域。

自动挖掘算法或独立策略层负责候选准入判断。引擎可以公开结构化诊断、依赖信息和算子元数据，供策略层使用，但不内置具体挖掘规则。

## 影响

- 研究、批量计算和自动挖掘复用同一个编译入口。
- 自动挖掘可以在引擎编译前后增加自己的轻量过滤。
- “纯常数是否有研究意义”等问题不属于引擎；只要计算域完整，引擎可以拥有明确的输出空间。
