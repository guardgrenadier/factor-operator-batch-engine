# core 用户手册

本文面向因子研究和生产使用者，说明如何用 `core/` 项目计算、物化、读取和维护因子。内容以当前代码为准：主要入口在 `core/__init__.py`，推荐使用 `FeatureManager.register(...)` 注册定义，再用 `FeatureManager.materialize(...)` 计算最终因子。

## 1. 核心概念

### 1.1 Snapshot

`FeatureStore` 管理一个固定的快照目录。快照包含：

- 交易日轴：`axes/dates.npy`
- 资产轴：每个资产一套固定 `InnerCode` 轴
- 日期敏感 code map：`SecuCode -> InnerCode`
- 已物化 feature：`features/{asset}/{freq}/{name}/`
- 全局索引：`manifest.json`

所有数组进入计算层后都是三维：

```text
T x N x S
date x asset x step
```

其中：

- `T` 是交易日数量。
- `N` 是当前资产轴中的 `InnerCode` 数量。
- `S` 是日内 step 数。日频 `1d` 为 `1`；`1min` 为 `237`；`5min/15min/30min/60min` 分别按完整 240 分钟会话生成 `48/16/8/4` 个 step。

### 1.2 Feature Key

所有 source 和 feature 都使用同一格式：

```text
asset.freq.name
```

例子：

```text
stk.1d.DailyReturn
stk.1d.close_adj_sus
stk.1min.close_price
stk.15min.close_15m
cb.1d.underlying_ret
idx.1d.ClosePrice
```

当前频率支持：

```text
1d, 1min, 5min, 15min, 30min, 60min
```

常用资产：

```text
stk = 股票
cb  = 可转债
idx = 指数
```

### 1.3 推荐使用方式

推荐路径：

```python
from core import FeatureManager, FeatureStore, FeatureDef, get_lf

store = FeatureStore("snapshot")
manager = FeatureManager(store)

manager.register(get_lf("DailyReturn", alias="ret"))
manager.register(
    FeatureDef.from_key(
        "stk.1d.ret_20d_mean",
        alias="ret_20d_mean",
        formula="ts_mean(ret, window=20, min_periods=20)",
        overwrite=True,
    )
)

feature = manager.materialize("ret_20d_mean", overwrite=True)
```

`materialize(...)` 会自动递归处理已注册依赖。通常只需要对最终因子调用一次 `materialize(...)`。

### 2.2 初始化 Snapshot

第一次使用一个快照目录时，需要初始化交易日轴和资产轴：

```python
from core import FeatureStore

store = FeatureStore("snapshot_2024")
store.init_snapshot(
    start="2024-01-01",
    end="2024-12-31",
    calendar="cn_a_share",
    assets=("stk", "cb", "idx"),
)
```

默认资产轴从数据库中读取：

- `stk`：`SmartQuant.ReturnDaily`
- `cb`：`SmartQuant.CBReturnDaily`
- `idx`：`JYDB.QT_IndexQuote`

也可以显式传入资产代码轴，适合小样本测试：

```python
store.init_snapshot(
    start="2024-01-01",
    end="2024-01-31",
    assets=("stk",),
    asset_codes={"stk": [1, 2, 3]},
    overwrite=True,
)
```

注意：当前设计不支持隐式扩轴。资产轴变化需要重新建 Snapshot 或做显式迁移。

## 3. 注册和物化因子

### 3.1 FeatureDef.from_key

通用定义入口是 `FeatureDef.from_key(...)`：

```python
from core import FeatureDef

fd = FeatureDef.from_key(
    "stk.1d.my_alpha",
    alias="my_alpha",
    formula="""
    cs_zscore(
        ts_mean(stk.1d.DailyReturn, window=20, min_periods=20)
    )
    """,
    input_mask=None,
    sample_mask="mask_not(stk.1d.IfSuspended)",
    output_mask="mask_not(stk.1d.is_untradable)",
    delay_lf=1,
    materialize=True,
    overwrite=True,
    metadata={"owner": "research"},
)
```

常用参数：

| 参数 | 含义 |
| --- | --- |
| `key` | 完整特征键，必须是 `asset.freq.name` |
| `alias` | 便于公式引用的别名 |
| `formula` | 字符串公式或内部 Expr |
| `dependencies` | 可手动声明依赖；注册时还会从公式和 mask 自动收集 |
| `input_mask` | 下推到所有输入叶子的 mask |
| `sample_mask` | 注入到截面、分组、成员统计等 sample-aware 算子 |
| `output_mask` | 对最终结果应用 mask |
| `delay_lf` | 日频叶子进入分钟输出时的默认日期延迟，默认 `1` |
| `delay_dict` | 对特定叶子覆盖 `delay_lf` |
| `steps` | 自定义 step 数，基本面多季度等场景会用到 |
| `materialize` | 是否写入 Store；中间 runtime feature 可设为 `False` |
| `overwrite` | 默认物化覆盖行为 |
| `metadata` | 业务元数据，不应承载核心计算语义 |

### 3.2 register 和 materialize

```python
from core import FeatureManager

manager = FeatureManager("snapshot_2024")
manager.register(fd)
out = manager.materialize("my_alpha", overwrite=True)
```

`materialize(...)` 支持：

```python
manager.materialize(
    "my_alpha",
    overwrite=True,
    chunk_size=None,
    workers=1,
    overlap=None,
    return_array=True,
)
```

说明：

- `overwrite=None` 时使用 `FeatureDef.overwrite`。
- `chunk_size=None` 表示全量一次计算。
- `chunk_size=20` 表示按 20 个写入交易日分块物化。
- 当前 chunk 物化只支持 `workers=1`。
- `overlap=None` 时会从 `delay`、日期 rolling、部分 intraday rolling 算子中推断所需历史窗口。
- `return_array=False` 可以只落盘不返回完整数组，适合大规模高频因子。

示例：

```python
manager.materialize(
    "stk.1d.day_night_reversal",
    overwrite=True,
    chunk_size=20,
    overlap=20,
    return_array=False,
)
```

### 3.3 定义持久化

`FeatureManager` 默认从 `{snapshot}/feature_defs` 加载定义，也可以显式保存和加载：

```python
manager.save_definitions()
manager.load_definitions()
```

定义按以下路径保存：

```text
feature_defs/{asset}/{freq}/{name}.json
feature_defs/aliases.json
```

`FeatureManager` 初始化时也会从已物化 feature 的 metadata 中恢复 alias。

## 4. Helper

### 4.1 get_lf：日频字段

`get_lf(...)` 用于生成日频字段定义：

```python
from core import get_lf

manager.register(
    get_lf(
        "ClosePrice",
        asset="stk",
        freq="1d",
        name="close_adj_sus",
        alias="close",
        if_adj=True,
        if_sus=True,
        overwrite=True,
    )
)
```

行为：

- 基础依赖是 `stk.1d.ClosePrice`。
- `if_adj=True` 时乘以 `stk.1d.adj_factor`。
- `if_sus=True` 时用 `stk.1d.IfSuspended` 过滤停牌。
- 若不传 `name`，默认使用字段名；启用复权和停牌过滤时会自动追加后缀。

### 4.2 get_hf：分钟字段

`get_hf(...)` 用于生成分钟字段定义：

```python
from core import get_hf

manager.register(
    get_hf(
        "close_price",
        asset="stk",
        freq="1min",
        alias="close_1m",
        materialize=False,
    )
)
```

legacy `get_hf` 只声明原始分钟 Source，不再承担重采样。新 batch pipeline 使用公开
`resample(expr, "15min", method="last")`，或等价的新版 `get_hf` 简写。细频率到粗频率
不会自动隐式聚合。

### 4.3 get_fund：基本面字段

`get_fund(...)` 用于生成带显式读取参数的基本面定义：

```python
from core import get_fund

manager.register(
    get_fund(
        "NPParentCompanyOwners",
        column_name="Value",
        quarters=4,
        data_code=None,
        publ_date_limit=-180,
        name="np_parent_q4",
        alias="np_parent_q4",
        overwrite=True,
    )
)

feature = manager.materialize("np_parent_q4", overwrite=True)
```

说明：

- `quarters=4` 会生成 `T x N x 4` 数组。
- `column_name` 是 `SmartQuant.Fundamental_Item{data_code}` 中读取的列。
- `data_code=None` 时会按 `field` 去 `SmartQuant.Fundamental_ItemCode` 查询唯一 `ItemCode`。
- `publ_date_limit` 控制 `InfoPublDate >= EndDate + publ_date_limit days`。
- `get_fund` 生成的 `FeatureDef` 会在物化前自动向 `DataRouter` 注册带完整参数的 `SourceSpec`。

## 5. 公式语言

### 5.1 基本语法

公式字符串会被 `FormulaParser` 转为内部表达式树。支持：

- 完整 feature key：`stk.1d.DailyReturn`
- alias：`ret`
- 常量：`1`、`0.5`、`True`
- 一元负号：`-x`
- 二元运算：`+`、`-`、`*`、`/`
- 比较：`>=`、`>`、`<=`、`<`、`==`、`!=`
- 简单函数调用：`ts_mean(x, window=20)`
- 字面量 keyword 参数

不建议使用 Python 的 `and/or/not`。逻辑 mask 请用：

```text
mask_and(...)
mask_or(...)
mask_not(...)
```

### 5.2 完整 key 和字符串

完整 key 可以直接写在公式中：

```python
formula = "stk.1d.ClosePrice / stk.1d.PrevClosePrice - 1"
```

如果某个 keyword 参数是完整 key 字符串，注册时会自动转为 feature 引用：

```python
formula = "neutralize(ret, exposure='stk.1d.FloatMarketCap')"
```

普通字符串参数不应写成完整 key 的形式。

### 5.3 可用算子

默认公式算子来自 `core/ops.py::default_operator_registry()`。

基础数学和比较：

| 算子 | 说明 |
| --- | --- |
| `add(x, y)` 或 `x + y` | 加法 |
| `subtract(x, y)` 或 `x - y` | 减法 |
| `multiply(x, y)` 或 `x * y` | 乘法 |
| `divide(x, y)` 或 `x / y` | 安全除法，无穷值转为 `nan` |
| `neg(x)` 或 `-x` | 取负 |
| `abs(x)` / `abs_val(x)` | 绝对值 |
| `log(x)` | 自然对数，非法值转为 `nan` |
| `sqrt(x)` | 平方根 |
| `greater_equal` / `greater` / `less_equal` / `less` / `equal` / `not_equal` | 比较 |
| `where(mask, x, y=np.nan)` | 条件选择 |

Mask：

| 算子 | 说明 |
| --- | --- |
| `apply_mask(x, mask)` | mask 为 False 的位置置 `nan` |
| `mask_and(*masks)` | 多个 mask 逻辑与 |
| `mask_or(*masks)` | 多个 mask 逻辑或 |
| `mask_not(mask)` | 逻辑非 |

时间序列：

| 算子 | 说明 |
| --- | --- |
| `delay(x, periods=1, axis=0)` | 沿指定轴滞后 |
| `ts_mean(x, window=5, min_periods=None, axis=0)` | rolling mean |
| `ts_sum(x, window=5, min_periods=None, axis=0)` | rolling sum |
| `ts_std(x, window=5, min_periods=None, axis=0)` | rolling std |
| `ts_min(x, window=5, min_periods=None, axis=0)` | rolling min |
| `ts_max(x, window=5, min_periods=None, axis=0)` | rolling max |

截面：

| 算子 | 说明 |
| --- | --- |
| `cs_mean(x, sample_mask=None)` | 按 date/step 沿资产轴广播截面均值 |
| `cs_zscore(x, sample_mask=None)` | 截面 zscore |
| `rank(x, sample_mask=None)` | 截面 rank，结果在 `(0, 1]` |
| `winsorize(x, sample_mask=None, lower=0.01, upper=0.99)` | 截面分位缩尾 |
| `neutralize(x, exposure, sample_mask=None)` | 对单个 exposure 回归取残差 |

Step 和高频：

| 算子 | 说明 |
| --- | --- |
| `get_step(x, step=0)` | 选择单个 step，保留 step 维 |
| `slice_step(x, start=None, end=None)` | 选择 step 区间 |
| `step_mean` / `step_sum` / `step_std` / `step_max` / `step_min` | 沿 step 聚合为单 step |
| `step_first(x)` / `step_last(x)` | 选择第一/最后 step |
| `step_corr(x, y)` | 沿 step 计算相关系数 |
| `step_delay(x, periods=1)` | 沿 step 滞后 |
| `step_diff(x, periods=1)` | step 差分 |
| `step_pct_change(x, periods=1)` | step 百分比变化 |
| `intraday_flat_mean(x, window_days)` | 过去多日所有 step 展平均值 |
| `intraday_flat_std(x, window_days)` | 过去多日所有 step 展平标准差 |
| `intraday_by_step_mean(x, window_days)` | 过去多日同一 step 均值 |
| `intraday_by_step_std(x, window_days)` | 过去多日同一 step 标准差 |
| `ffill_to_finer_steps(x, step_index)` | 粗分钟到细分钟前向填充，通常由 Planner 生成 |

分组、指数成员和广播：

| 算子 | 说明 |
| --- | --- |
| `group_mean/sum/std/demean/zscore(x, group, sample_mask=None, weight=None)` | 按分组统计 |
| `member_mean/sum/std/demean/zscore(x, member, sample_mask=None, weight=None)` | 在指数成员内统计 |
| `broadcast_cs(x)` | 将每个截面的单一统计值广播到所有资产 |
| `lookup_by_col(source_values, source_col)` | 按列位置从源资产轴映射到目标资产轴 |
| `select_by_pos(x, pos, axis=1, keepdims=False)` | 按位置选择 |
| `broadcast_ts(x, n_assets)` | 时间序列广播到资产轴 |
| `broadcast_to_steps(x, n_steps)` | 单 step 广播到多个 step |

### 5.4 公式 helper

公式中也支持这些 helper，它们在解析阶段展开为普通表达式：

```python
broadcast_index_feature(index="CSI300", feature="idx.1d.ClosePrice")
index_member_stat(ret, index="CSI300", method="mean", broadcast=True)
industry_stat(ret, method="zscore", system="SW2021", level=1)
industry_mean(ret)
industry_demean(ret)
industry_zscore(ret)
```

`index_member_stat` 的 `method` 支持：

```text
mean, sum, std, demean, zscore
```

`industry_stat` 的 `method` 支持：

```text
mean, sum, std, demean, zscore
```

## 6. Mask 和延迟

### 6.1 input_mask

`input_mask` 会下推到公式中的所有输入叶子，适合统一过滤输入数据：

```python
FeatureDef.from_key(
    "stk.1d.ret_clean_mean",
    formula="ts_mean(stk.1d.DailyReturn, window=20)",
    input_mask="mask_not(stk.1d.IfSuspended)",
)
```

### 6.2 sample_mask

`sample_mask` 只注入到 sample-aware 算子：

```text
cs_mean, cs_zscore, rank, winsorize, neutralize,
group_mean, group_sum, group_std, group_demean, group_zscore,
member_mean, member_sum, member_std, member_demean, member_zscore
```

示例：

```python
FeatureDef.from_key(
    "stk.1d.ret_rank",
    formula="rank(stk.1d.DailyReturn)",
    sample_mask="mask_not(stk.1d.is_untradable)",
)
```

如果提供了 `sample_mask`，但公式中没有 sample-aware 算子，计算时会发出 warning，并把 warning 写入 metadata。

### 6.3 output_mask

`output_mask` 应用于最终结果：

```python
FeatureDef.from_key(
    "stk.1d.ret_final",
    formula="cs_zscore(stk.1d.DailyReturn)",
    output_mask="mask_not(stk.1d.is_untradable)",
)
```

### 6.4 delay_lf 和 delay_dict

当日频叶子被用于分钟输出时，Planner 会默认延迟 `delay_lf=1`，避免未来函数：

```python
FeatureDef.from_key(
    "stk.1min.ret_plus_close",
    formula="stk.1min.close_price + stk.1d.DailyReturn",
    delay_lf=1,
)
```

对特定叶子可覆盖：

```python
FeatureDef.from_key(
    "stk.1min.example",
    formula="stk.1min.close_price + stk.1d.DailyReturn + stk.1d.FloatMarketCap",
    delay_lf=1,
    delay_dict={"stk.1d.FloatMarketCap": 0},
)
```

## 7. 数据源

### 7.1 DataRouter 解析优先级

当公式引用一个叶子 key 时，执行器按以下顺序读取：

1. 当前计算会话的 runtime feature。
2. `FeatureStore` 中已物化 feature。
3. `DataRouter` 读取外部 source。

`DataRouter.resolve_source(key)` 的 source 解析优先级：

1. `memory_data`
2. `source_overrides`，即 `register_source(SourceSpec(...))`
3. `core/data_sources.json["sources"]` 精确配置
4. `core/data_sources.json["source_tables"]` 扫描出的字段目录

不会只凭裸字段名宽松匹配 source。

### 7.2 默认 data_sources.json

当前 `core/data_sources.json` 包含 5 个表级配置：

| asset | freq | source | 说明 |
| --- | --- | --- | --- |
| `stk` | `1d` | `ReturnDaily` | 股票日行情表 |
| `cb` | `1d` | `CBReturnDaily` | 转债日行情表 |
| `idx` | `1d` | `IndexQuote` | 指数日行情表 |
| `stk` | `1min` | `MinuteParquet` | 股票 1min parquet |
| `cb` | `1min` | `MinuteParquet` | 转债 1min parquet |

还包含若干精确 source：

```text
stk.1d.adj_factor
stk.1d.is_untradable
cb.1d.underlying_stk_col
cb.1d.underlying_stk_inner_code
stk.1d.industry_code.SW2021.L1
stk.1d.index_weight.CSI300
stk.1d.is_member.CSI300
```

### 7.3 搜索字段

可以搜索当前 source 字段目录：

```python
router = manager.data_router
print(router.search("ClosePrice").head())
print(router.search("净利润").head())
```

注意：`search(...)` 来自实时扫描的 `data_dict`，用于发现普通表字段和基本面 item code。精确 `sources` 字典中的特殊 key 不一定都出现在搜索结果里。

## 8. 导入外部数据

### 8.1 import_array

```python
feature = store.import_array(
    "stk.1d.external_alpha",
    values,          # 2D T x N 或 3D T x N x S
    dates=dates,     # 可选，若 values 只是部分日期
    codes=codes,     # 可选，若 values 只是部分资产
    overwrite=True,
)
```

整数数组会转为 float，以便用 `nan` 表示缺失；bool 数组缺失值为 `False`。

### 8.2 import_dataframe

```python
feature = store.import_dataframe(
    "stk.1d.external_alpha",
    df,
    date_col="DataDate",
    code_col="SecuCode",
    value_col="value",
    overwrite=True,
)
```

`code_col` 支持：

- `InnerCode`
- `SecuCode`

如果传 `SecuCode`，会用 Snapshot 的 code map 转成 `InnerCode`。

分钟或多 step 长表可传 `step_col`：

```python
store.import_dataframe(
    "stk.1min.external_signal",
    df,
    date_col="DataDate",
    code_col="SecuCode",
    step_col="start_time",
    value_col="value",
    overwrite=True,
)
```

## 9. 跨资产和指数

### 9.1 股票到转债

当目标资产是 `cb`，公式引用 `stk.*` 特征时，Planner 会使用：

```text
cb.1d.underlying_stk_col
```

把股票资产轴按转债正股映射到转债资产轴：

```python
manager.register(get_lf("DailyReturn", asset="stk", alias="stk_ret"))
manager.register(
    FeatureDef.from_key(
        "cb.1d.underlying_ret",
        formula="stk_ret",
        overwrite=True,
    )
)
out = manager.materialize("cb.1d.underlying_ret", overwrite=True)
```

### 9.2 指数特征广播

`idx.*` 资产轴不能自动混入 `stk` 或 `cb`，需要显式选择指数：

```python
manager.register(
    FeatureDef.from_key(
        "stk.1d.ret_ex_csi300",
        formula="""
        stk.1d.DailyReturn
        - broadcast_index_feature(index="CSI300", feature="idx.1d.DailyReturn")
        """,
        overwrite=True,
    )
)
```

当前 `INDEX_INNER_CODES` 中只有 `CSI300=3145` 已确认。其他指数如果未配置 `InnerCode`，使用时会报错，需要先在 `core/sources.py` 中维护映射。

### 9.3 指数成员统计

```python
manager.register(
    FeatureDef.from_key(
```

## 10. 高频例子：昼夜合成反转

以下例子对应 `core/docs/昼夜合成反转因子_框架计算方案.md` 中的口径。

```python
import numpy as np
from core import FeatureDef, FeatureManager, FeatureStore, get_hf, get_lf
from core.schema import get_freq_step_values

store = FeatureStore("snapshot_2024")
manager = FeatureManager(store)

pos_1000 = int(np.where(get_freq_step_values("1min") == 1000)[0][0])

manager.register(get_hf("close_price", asset="stk", freq="1min", materialize=False), overwrite=True)
manager.register(get_lf("OpenPrice", name="OpenPrice_Adj_Sus", if_adj=True, if_sus=True), overwrite=True)
manager.register(get_lf("ClosePrice", name="ClosePrice_Adj_Sus", if_adj=True, if_sus=True), overwrite=True)

manager.register(
    FeatureDef.from_key(
        "stk.1d.intra_1000_close_logret",
        formula=f"""
        log(
            step_last(
                divide(
                    stk.1min.close_price,
                    get_step(stk.1min.close_price, step={pos_1000})
                )
            )
        )
        """,
        materialize=False,
    ),
    overwrite=True,
)

manager.register(
    FeatureDef.from_key(
        "stk.1d.intraday_return_20",
        formula="ts_mean(stk.1d.intra_1000_close_logret, window=20, min_periods=20)",
        materialize=False,
    ),
    overwrite=True,
)

manager.register(
    FeatureDef.from_key(
        "stk.1d.overnight_gap",
        formula="""
        abs(
            log(
                divide(
                    stk.1d.OpenPrice_Adj_Sus,
                    delay(stk.1d.ClosePrice_Adj_Sus, periods=1, axis=0)
                )
            )
        )
        """,
        materialize=False,
    ),
    overwrite=True,
)

manager.register(
    FeatureDef.from_key(
        "stk.1d.overnight_gap_20",
        formula="ts_sum(stk.1d.overnight_gap, window=20, min_periods=10)",
        materialize=False,
    ),
    overwrite=True,
)

manager.register(
    FeatureDef.from_key(
        "stk.1d.day_night_reversal",
        formula="""
        -(
            0.6 * stk.1d.intraday_return_20
            + 0.4 * stk.1d.overnight_gap_20
        )
        """,
        output_mask="""
        equal(
            ts_sum(stk.1d.is_untradable, window=20, min_periods=1),
            0
        )
        """,
        overwrite=True,
        metadata={"factor": "day_night_reversal"},
    ),
    overwrite=True,
)

manager.materialize(
    "stk.1d.day_night_reversal",
    overwrite=True,
    chunk_size=20,
    overlap=20,
    return_array=False,
)
```

### 11.5 常见错误

| 现象 | 常见原因 |
| --- | --- |
| `Snapshot is not initialized` | 还没有调用 `FeatureStore.init_snapshot(...)` |
| `FeatureDef ... is already registered` | 重复注册且未传 `overwrite=True` |
| `Alias ... is already registered` | alias 被其他 key 占用 |
| `Source ... is not registered in data_dict` | `data_sources.json` 未配置该 source，或字段扫描失败 |
| `OB_USER/OB_PASSWORD are required` | 数据库账号未配置 |
| `MinuteParquet source reading requires duckdb` | 缺少 `duckdb` |
| `Cannot implicitly resample fine frequency ... into coarse frequency` | 细分钟到粗分钟需要使用新 batch pipeline 的公开 `resample(...)` |
| `Index ... does not have a confirmed InnerCode yet` | `INDEX_INNER_CODES` 未维护该指数 |
| `Chunked materialize currently supports workers=1 only` | 当前 chunk 物化不支持并行 worker |
| `Feature ... was written against a different snapshot axis` | 物化特征与当前 Snapshot 轴不一致 |
