# 资产轴对齐规则

- 状态：已确认并同步到正式设计和 batch engine 核心实现
- 日期：2026-08-11
- 目的：明确资产选择、指数成分统计、分组统计和跨资产投影的 Domain 与 Runtime 边界
- 相关规则：[`频率与第三维对齐规则.md`](频率与第三维对齐规则.md)、
  [`取数对象与DAG编译链路.md`](取数对象与DAG编译链路.md)、
  [`独立DataProvider设计.md`](独立DataProvider设计.md)

## 1. 核心原则

选择一只股票、选择一个指数和计算整个截面的统计值，业务语义由不同 helper/operator 表达，但它们都可以产生 `T × 1 × S` 数组。后续与 `T × N × S` 数组运算时，由 NumPy 自动完成资产维 singleton `1 → N` 广播。

推荐分层：

```text
helper / operator
  负责“选择谁、统计什么、样本是什么”
  输出语义正确的 T × 1 × S

Compiler
  校验资产维 shape 和完整资产轴身份
  推导 operator 输出使用哪个完整资产 Domain
  不插入物理广播节点

Runtime / NumPy
  在普通数组运算中自动执行 1 → N
  不提前创建 T × N × S 广播副本
```

首版不引入 CoordinateAssetDomain、BroadcastAssetDomain 或 `asset_broadcastable`。所有合法的 `N=1` tensor 都遵循相同的 NumPy 资产维广播规则。

## 2. 单一 TermDomain

资产维继续由同一个 `TermDomain` 描述，不建立第二套 Domain 类型：

```text
asset_type
codes / anonymous singleton
axis_fingerprint
```

不同 operator 通过输出 shape 和语义身份表达差异：

- 单资产选择结果：`N=1`，operator semantic identity 记录选择的资产代码；
- 单指数选择结果：`N=1`，operator semantic identity 记录选择的指数代码；
- 截面 reduce 结果：`N=1`，operator semantic identity 记录统计方法和样本；
- 完整资产结果：`N>1`，Domain 保留真实 asset type、codes 和 axis fingerprint。

上述 singleton 的来源不同，但普通数值运算只需要知道其资产维长度为 1。来源语义继续参与 Term semantic identity、CSE 和诊断，不需要通过不同 Domain 类重复表达。

实现中完整轴和显式选择使用真实 `codes`；没有真实资产坐标的截面/member reduce 使用 `codes=None`，其 `asset_count` 属性为 1。

## 3. scalar 与资产 singleton

scalar 是没有 `T/N/S` Domain 的零维字面量，例如：

```python
close + 1
returns * 100
where(mask, values, 0)
```

其中 `1`、`100` 和 `0` 是零维 LiteralTerm：

```text
shape = ()
domain = None
```

它与 `T × 1 × S` 不同：

- scalar 没有日期、资产和 step 轴，可以沿所有维度广播；
- `T × 1 × S` 仍是一条随日期和 step 变化的时间序列，只在资产维为 singleton；
- 两者都由 NumPy 执行物理广播，但 Compiler 的 Domain 推导不同。

## 4. 普通 operator 的资产轴规则

普通逐元素 operator 收集全部非 scalar tensor 输入后，按 NumPy 规则合并资产维：

```text
N == N  -> N
1 与 N  -> N
N 与 1  -> N
M 与 N  -> 不兼容，其中 M != N 且 M/N 均不为 1
```

Domain 推导规则：

1. 忽略 scalar literal 的资产 Domain；
2. 如果存在一个 `N>1` 输入，输出继承它的完整资产 Domain；
3. 如果存在多个 `N>1` 输入，它们必须具有相同 asset type、codes 顺序和 axis fingerprint；
4. 任意数量的 `N=1` 输入可以与唯一的完整资产轴进行 NumPy 广播；
5. `N=1` 输入的原 asset type 不限制其广播目标，因此单指数可以广播到股票或转债轴；
6. 如果所有 tensor 输入都是 `N=1`，输出继续保持 `N=1`；
7. 如果没有 tensor 输入，输出没有资产 Domain；
8. 两个不同的完整资产轴不能因为资产数量相同而直接计算。

伪代码：

```python
full_domains = [domain for domain in inputs if domain.asset_count > 1]

if not full_domains:
    output_asset_count = 1
elif not all_same_axis(full_domains):
    raise DomainError("operator mixes incompatible asset axes")
else:
    output_domain = full_domains[0]
```

frequency、step_count 和 ValueKind 继续使用各自独立的规则检查。

## 5. 资产轴情况总表

| 场景 | 典型输入 shape | 语义表达位置 | 推荐输出 | 物理做法 |
| --- | --- | --- | --- | --- |
| 相同完整资产轴计算 | `T×N×S` 与 `T×N×S` | 普通 operator | 原完整资产轴 | 直接计算，轴身份必须一致 |
| scalar 与资产数组 | scalar 与 `T×N×S` | 普通 operator | 原完整资产轴 | NumPy scalar broadcast |
| 选择单只股票 | `T×N×S` | asset helper + 通用选择 operator | `T×1×S` | 保持维度的 slice/view |
| 选择单个指数 | `T×N_idx×S` | index helper + 通用选择 operator | `T×1×S` | 保持维度的 slice/view |
| singleton 与完整轴计算 | `T×1×S` 与 `T×N×S` | 普通 operator | 完整轴 `T×N×S` | NumPy 自动广播 |
| 截面 reduce | `T×N×S` | `cs_mean/cs_sum/cs_std` | `T×1×S` | 直接返回小数组 |
| 截面 transform | `T×N×S` | `rank/cs_zscore/winsorize/neutralize` | 原完整轴 `T×N×S` | 每个资产产生结果 |
| 指数成分池 reduce | values + member mask | member reduce operator | `T×1×S` | 统计样本后返回小数组 |
| 指数成分内 transform | values + member mask | member transform operator | 原完整轴 `T×N×S` | 成员位置计算 |
| 行业/分类统计并回填 | values + group code | generic group operator | 原完整轴 `T×N×S` | 按 group code gather/scatter |
| 行业内 transform | values + group code | generic group operator | 原完整轴 `T×N×S` | operator 直接计算每只资产结果 |
| 股票投影到转债 | stk values + relation | 业务 helper + generic gather | cb 完整轴 | 显式关系映射 |
| 转债聚合到股票 | cb values + relation + reducer | 业务 helper + generic reduction | stk 完整轴 | 显式多对一聚合 |
| singleton 最终输出 | `T×1×S` | 前序 selector/reducer | 请求目标资产轴 | 输出边界 `np.broadcast_to` view |

## 6. 资产子集和顺序

当前主要场景不依赖资产数量大于一的子集选择或资产轴重排，本次简化不为 subset/reindex 建设额外 operator 和对齐策略。

但当普通 operator 同时收到两个 `N>1` 输入时，仍保留现有轴身份校验：

```text
asset_type 相同
codes 及顺序相同
axis_fingerprint 相同
```

该校验成本很低，可以防止未来相同 shape、不同资产顺序的静默错算。是否从公共 `DomainSpec.asset_scope` 删除显式子集能力属于独立 API 决策，不影响本规则。

## 7. 单资产与单指数选择

### 7.1 helper 表达业务语义

股票、指数等业务概念放在 helper 中：

```python
select_asset(values, code=101)
select_index_feature(values, code="000300")
```

helper 可以先展开为保留稳定代码的内部表达式：

```text
__select_asset(values, code)
```

输入 Term 的资产 Domain 解析完成后，Compiler 根据当前冻结的 codes 把稳定代码解析为位置：

```text
code -> pos
```

最终 Lower 为不感知业务语言的通用数组 operator：

```python
select_by_pos(values, pos=pos, axis=1, keepdims=True)
```

Runtime operator 不需要知道股票、指数、InnerCode 或指数代码规则。

### 7.2 保持维度且避免复制

Runtime 优先使用保持资产维的切片：

```python
selected = values[:, pos : pos + 1, :]
```

基础数组允许时该结果是 view，shape 为 `T × 1 × S`。

### 7.3 后续隐式广播

选择结果与完整资产数组运算：

```text
selected: T × 1 × S
values:   T × N × S
```

普通 NumPy operator 直接计算：

```python
result = values - selected
```

不要求用户增加 `broadcast_cs`，也不提前执行：

```python
np.broadcast_to(selected, values.shape).copy()
```

输出 Term 继承 `values` 的完整资产 Domain。

## 8. 指数特征选择与成员统计

### 8.1 设计边界

新框架不实现“指数到股票/转债的关系映射”。指数场景只有两种语义：

1. 从指数轴选出一只指数的特征，得到 `T × 1 × S`；
2. 使用股票轴上的指数成分 mask 对股票特征做统计，得到 `T × 1 × S`。

两者所需 Source 都由用户在 `common_inputs` 中显式声明。helper 不注册指数特征、
成分数据或位置 mapping，也不插入面向目标资产轴的物理广播 operator。

### 8.2 选择单个指数特征

用户调用：

```python
common_inputs = """
stock_close = source("stk.1d.ClosePrice")
index_close = source("idx.1d.ClosePrice")
"""

formula = """
hs300_close = select_index_feature(index_close, 300)
factor = stock_close / hs300_close
"""
```

`select_index_feature()` 只从已有指数表达式中选择一个指数：

```text
source("idx.1d.ClosePrice")
  -> SourceRefExpr
  -> select_index_feature(values, 300)
  -> __select_asset(expected_asset_type="idx", code=300)
  -> Compiler 使用已冻结 idx.codes 解析 code -> pos
  -> select_by_pos(values, pos, axis=1, keepdims=True)
  -> T × 1 × S
  -> 与 stk/cb T × N × S 运算
  -> NumPy 自动广播
```

输入必须是 `idx` 完整轴。helper 负责保留稳定指数代码语义，
Compiler 负责把代码解析为当前任务位置，Runtime 只做通用切片。

### 8.3 指数成分池统计

用户同时显式声明股票特征和成分 mask：

```python
common_inputs = """
stock_close = source("stk.1d.ClosePrice")
hs300_member = source("stk.1d.is_member.HS300")
"""

formula = """
factor = index_member_stat(stock_close, hs300_member, method="mean")
"""
```

```text
stock values: T × N × S
member mask:  T × N × 1
  -> index_member_stat(values, member, method="mean")
  -> member_mean(values, member)
  -> T × 1 × S
```

`mean/sum/std` 分别复用现有 `member_mean/member_sum/member_std`。values 与
member 必须使用同一条完整股票轴。统计结果不需要先“广播回去”：
它与完整股票/转债数组参与普通运算时会自动广播。如果业务上只希望成分股
保留统计值，调用方显式使用 `apply_mask(stat, member)`。

## 9. 截面统计

截面 operator 分为 reduce 和 transform。

### 9.1 截面 reduce

例如：

```text
cs_mean
cs_sum
cs_std
```

确认契约：

```text
input  = T × N × S
output = T × 1 × S
```

例如 `cs_mean` 直接返回：

```python
np.nanmean(masked, axis=1, keepdims=True)
```

不在 operator 内广播并 `.copy()` 成 `T × N × S`。只有后续公式实际与完整资产轴运算时，NumPy 才执行 `1 → N`。

### 9.2 截面 transform

例如：

```text
rank
cs_zscore
winsorize
neutralize
```

这些 operator 的每只资产输出不同，必须返回原完整资产轴：

```text
input  = T × N × S
output = T × N × S
```

### 9.3 `broadcast_cs`

采用隐式 NumPy 资产广播后，不再需要用户显式调用 `broadcast_cs`。

当前 `broadcast_cs()` 会扫描完整资产轴、检查有限值是否一致，并创建完整输出数组；它不是简单的 singleton view。新架构下应将其从推荐公式语言和默认 Registry 中删除，或只保留在 legacy 层。

## 10. 指数成分池统计

指数成分 mask 与 values 使用相同完整资产轴，step 维继续遵守 singleton 广播规则。

### 10.1 成分池 reduce

如果目标是得到成分股集合的统计时间序列：

```text
member_mean / member_sum / member_std
  input  = values + member mask
  output = T × 1 × S
```

结果可以在后续普通 operator 中广播到完整股票、转债或其他目标资产轴。

### 10.2 成分内 transform

如果目标是对每个成员进行变换：

```text
member_demean / member_zscore
  output = T × N × S
```

非成员位置的行为由 operator 契约确定，不属于资产广播规则。

`member_mean/member_sum/member_std` 已是真正的 reduce，原生输出为
`T × 1 × S`；不在 operator 内回填成员位置。

## 11. 行业和其他分类统计

首版采用最直接的通用方案：把分类列作为 Term 输入传给 group operator。

```python
group_mean(values, group_code)
group_sum(values, group_code)
group_std(values, group_code)
group_demean(values, group_code)
group_zscore(values, group_code)
```

输入输出：

```text
values:     T × N × S
group_code: T × N × 1 或 T × N × S
output:     T × N × S
```

operator 内部负责：

1. 按 group code 识别分类；
2. 在每组样本内计算统计量；
3. 根据每只资产的 group code 回填统计值或变换结果；
4. 返回与 values 相同的完整资产 Domain。

这不是 NumPy singleton broadcast。不同资产需要读取不同组的结果：

```text
output[t, n, s] = group_stat[t, group_code[t, n], s]
```

因此必须由 operator 内部执行 gather/scatter。首版不把临时 `G` 个分类轴引入 TermDomain，也不增加 grouped lazy array Runtime 类型。

行业业务语义由 helper 表达：

```text
industry_mean(values, standard="SW2021", level=1)
  -> industry group SourceRef
  -> group_mean(values, group_code)
```

底层 group operator 不感知行业，也可以服务地区、评级或其他分类。

## 12. 跨资产轴投影

完整股票轴、转债轴和指数轴之间不能因为资产数量相同而直接计算。除了 singleton 广播，完整轴之间必须显式映射。

### 12.1 股票到转债

用户只声明股票特征，不需要声明 mapping Source：

```python
common_inputs = """
stock_close = source("stk.1d.ClosePrice")
"""

formula = """
stock_signal = ts_mean(stock_close, 5)
factor = project_stk_to_cb(stock_signal)
"""
```

完整调用链：

```text
project_stk_to_cb(values)
  -> HelperExpander 自动注入 SourceRefExpr("cb.1d.underlying_stk_col")
  -> lookup_by_col(values, underlying_stk_col)
  -> SourceDescriber / DomainResolver 将 mapping 识别为 cb 轴 CODE Source
  -> bind_many() 按当前转债 ReadDomain 绑定 CBStockMap
  -> load_many() / _cb_stock_map()
       读取 cb InnerCode -> StockInnerCode
       使用当前 Provider 的 axes["stk"] 将 StockInnerCode 换成股票列位置
       生成 T × N_cb × 1 的 underlying_stk_col
  -> Runtime lookup_by_col(stock_values, underlying_stk_col)
  -> T × N_cb × S
```

`_cb_stock_map()` 内固定引用股票轴，不引入 `reference_asset` 参数或通用关系协议。
原始 StockInnerCode 不在当前任务 `stk.codes` 中时，mapping 为 NaN，对应转债
结果也为 NaN。Runtime kernel 不感知股票或转债。

正式 Provider 是任务级实例，位置映射只使用该实例冻结的 `stk.codes`
生成，可以在该任务内复用，但不得进入跨任务缓存，也不得复用基于
legacy Store master axis 的列号。已移除的兼容层 `FeatureStoreDataProvider`
不具备这一任务轴契约，曾在 describe 阶段拒绝该 mapping Source；该能力现在
只由正式 `SmartQuantDataProvider` 提供。

### 12.2 转债到股票

多只转债可能映射到同一股票，必须由 helper/公式显式声明 selector 或 reducer，不能自动投影。

## 13. 输出边界

最终公式输出：

- `N>1` 时必须与请求的 target asset axis 完全一致；
- `N=1` 时允许在输出边界通过 `np.broadcast_to()` 扩展到 target asset count；
- 输出边界不自动 reindex、关系投影或资产聚合。

`stream()` 可以交付只读 broadcast view，避免中间完整复制。`compute()` 装配最终完整结果数组时仍会写入目标数组；该内存属于最终结果，而不是可消除的中间广播成本。

Runtime、operator 结果校验和 ResultChunk 必须接受合法的只读、非连续及 zero-stride ndarray view，不能要求每个结果拥有独立连续 buffer。

## 14. 对 `_lower()` 的影响

普通 operator 的 Domain rule 同时处理 step 与 asset 两个 NumPy singleton 维度：

```text
lower inputs
  -> 校验 ValueKind
  -> 合并 frequency / step_count
  -> 合并 asset_count
  -> 多个 N>1 输入校验完整轴身份
  -> 输出继承非 singleton frequency、step 和 asset Domain
```

特殊语义仍由显式 operator/helper 处理：

```text
select helper      -> code 解析 -> generic select_by_pos
industry helper    -> group SourceRef -> generic group operator
stk/cb helper      -> relationship binding -> generic gather/reduce
```

Compiler 不插入 `broadcast_cs`、`broadcast_ts` 或 `__index_broadcast` 等物理扩展节点。

## 15. 对现有实现的调整

### 删除或退出新主线

- `broadcast_cs`；
- 负责物理扩展的 `broadcast_ts(x, n_assets)`；
- `__index_broadcast` 内部 operator。

### 改为 singleton 输出

- `cs_mean`，并补充 `cs_sum/cs_std`；
- `member_mean/member_sum/member_std`；
- 单资产和单指数选择。

### 保持完整资产输出

- rank、cs_zscore、winsorize、neutralize；
- group mean/sum/std 的分组回填；
- group demean/zscore；
- member demean/zscore；
- stk/cb relationship projection。

### 保留的安全校验

- 多个 `N>1` 输入的 asset type、codes 和 axis fingerprint；
- selector 的代码存在性；
- group/member 输入与 values 的完整资产轴一致性；
- relationship mapping 与源/目标轴一致性；
- 最终输出与 target asset axis 一致性。

## 16. 验收条件

1. 相同完整资产轴可以直接计算。
2. 两个不同完整资产轴即使 shape 相同也在编译期失败。
3. scalar 可以与任意合法 tensor 运算。
4. 显式选择单只股票后返回 `T × 1 × S` view。
5. 显式选择指数后返回 `T × 1 × S`，可以隐式广播到股票或转债轴。
6. 任意合法 `N=1` tensor 与 `N>1` tensor 运算时由 NumPy 自动广播。
7. 所有输入都是 `N=1` 时，输出继续保持 singleton。
8. singleton 最终输出可以广播到请求目标资产轴。
9. 截面 reduce 返回 `T × 1 × S`，不创建完整资产副本。
10. 截面 transform 返回原完整资产轴。
11. `broadcast_cs`、`broadcast_ts` 和 `__index_broadcast` 不再出现在新 LogicalPlan 中。
12. 行业统计传入 group code，并在 operator 内部回填完整资产轴。
13. 成分池 reduce 与成分内 transform 具有不同、确定的输出 shape。
14. 股票到转债映射使用当前任务稳定代码轴，资产子集或代码顺序变化时不会复用错误列位置。
15. Runtime 和 ResultChunk 接受只读、非连续及 zero-stride view。
16. 优化前后数值结果一致，并减少 singleton 广播产生的中间完整数组分配。
